# 🐍 Python Practice Folder

> 이 폴더에는 Python 연습 파일 모음이 들어있습니다.  
> 모든 파일은 직접 실행하며 학습한 내용을 기록한 포트폴리오용 실습 파일입니다.

---

## 🔹 폴더 목적
- 단순 개념 정리가 아니라, 코드 실행 → 출력 → 배운 점 순으로 작성
- 오류, 수정 과정까지 포함하여 성장 과정을 보여줍니다.
- README/스터디 파일과 차별화된 '실제 경험 중심' 연습 파일 모음

## 🔹 사용법
1. 로컬로 클론 후 Python 3 이상에서 실행
2. 각 파일 열고 실행 → 출력 결과 확인
3. 상단 통일 문구 포함 → ‘배운 점’ 주석 확인

## 🔹 특징
- 모든 연습 파일 상단에 포트폴리오용 통일 문구 포함
- 짧고 핵심적인 실습 중심
- 오류, 수정, 출력 기록 포함 → 성장 과정 강조
