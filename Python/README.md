## 🐍 1. 주석 사용법 및 기초

- 주석: 코드 옆에 설명하는 글, 코드와 구분을 하기 위해 '#'을 앞에 붙인다.
- 한줄메모는 `#`,
- 여러줄 메모는 `'''`또는 `"""`

(ex) 
```python
3 #정수 
'안녕' #문자열 
#한줄 메모 
'''       """
여러줄     여러줄
메모       메모
'''       """
```
- print(): 파이썬에서 가장 기본이 되는 함수, 데이터를 출력하기 위해 사용되는 함수
 - \n -> 줄 바꿈
 - \t -> 탭

🧠 정리
주석을 사용하면 코드의 의도를 명확히 표현할 수 있고,
나중에 코드를 다시 확인할 때 전체 흐름을 빠르게 이해/파악할 수 있다.

## 🐍 2. 변수와 자료형
- 자료형: 문자와 숫자 등 다양한 자료의 종류
  - 숫자형: 숫자로 이루어진 자료형
  - 문자열: 문자로 이루어진 자료형
  -> 문자 앞뒤에 `' '` 또는 `" "` 사용 
  -> 따옴표 세개(`'''` 또는 `"""`)를 사용하면 여러 줄 문자열 작성 가능

- 리스트(List): 자료 목록, 리스트 안에는 자료형
 - 숫자형, 문자열 등 서로 다른 자료를 함께 저장 가능

- 변수(Variable): 데이터를 저장하는 메모리 공간

변수 이름 규칙:
(1) 숫자, 알파벳, 한글, 언더스코어(_) 등은 사용 가능
(2) 첫 글자는 숫자로 시작할 수 없음
(3) 숫자로만 구성된 변수 이름은 불가능
(4) 파이썬 문법에서 사용하는 예약어 (예: for, while, if 등) 는 변수 이름 사용 불가
(5) 빈칸과 연산자(+, -, % 등) 는 변수 이름안에 사용 불가

🧠 정리
변수는 값을 저장하는 공간이며,
자료형에 따라 저장되고 처리되는 방식이 달라진다는 점을 이해했다.

## 🐍 5. 리스트와 슬라이싱
- 인덱스(Index): 원소의 순서 , 원소의 순서는 0부터 시작
- 인덱싱(Indexing): 인덱스를 이용하여 특정 위치의 원소를 불러오는 것
- 기본형: 문자열[인덱스] , 리스트[인덱스]
- 슬라이싱(Slicing): 문자열이나 리스트의 일부분을 잘라서 가져오는 것
- 기본형: 문자열[a:b] , 리스트[a:b]

설명:
- a: 시작 인덱스
- b: 종료 인덱스
종료 인덱스는 항상 가져올 인덱스보다 1 큰 값
- 리스트안에 또다른 리스트가 있을 시, 
  [인덱스][인덱스] 를 사용

🧠 정리
리스트와 문자열은 같은 방식으로 인덱싱과 슬라이싱이 가능하며, 종료 인덱스는 포함되지 않는다는 점을 명확히 이해했다.

## 🐍 7. 자료형 형 변환
- 형 변환: 어떤 자료형을 다른 자료형으로 바꾸는 것
- 기본형: 형 변환 함수(자료)
- 형 변환 함수: 프로그래밍 및 데이터 베이스에서 특정 자료형(데이터 타입)을 다른 자료형으로 변환하여 데이터의 형식을 변경하는 함수

|  구분  |   이름   |   형 변환 함수   |
|:------:|:--------:|:--------------:|
|  정수  | integer |      int()      |
|  실수  |  float  |    float()      |
| 문자열 |  string  |     str()      | 
| 리스트 |   list   |     list()     |

에러 상황 및 이유 설명
- input(''): 아무것도 입력 안함
- input(' '): 공백
- input(10,000): 쉼표로 인해 정수가 아닌 문자열 형태
- input(20살): 문자 포함
- input(3.5): 소수점 문자열은 int()로 직접 변환 불가

🧠 정리
형 변환 함수의 종류를 구분할 수 있게 되었고,
input() 사용 시 입력값이 문자열로 처리된다는 점과
자료형에 따라 에러가 발생할 수 있다는 점을 이해했다.

## 8. 🐍 비교 연산과 논리 연산
- 논리형(Boolean): 참(True) 과 거짓(False) 단 두 가지 값만으로 논리적인 상태를 표현하는 자료형
- 조건문과 논리 연산의 결과로 주로 사용된다.

### 1. 비교연산
- 비교 연산: 두 가지 자료를 비교하는 과정
- 비교 연산자: 비교 연산할 때 사용하는 연산자
- 부등식: 두 숫자 또는 두 식의 크기를 비교하는 수식
- 부등호: 부등식에서 사용하는 기호

|  구분  |  기호  |
|:------:|:------:|
|  같다  |   ==   |
| 같지 않다 |  !=  |
| 왼쪽이 더 크다 | > |
|오른쪽이 더 크다 | < |
| 같거나 왼쪽이 더 크다 | >= |
|같거나 오른쪽이 더 크다 | <= |

### 2. 논리 연산
- 논리 연산: 두 논리를 연결할 때 사용
- 논리 연산자: 논리 연산 할 때 사용하는 연산자
  종류: and, or, not
- and 연산자: 조건이 모두 True 일때 True

| 과정 | 결과 |
|:----:|:----:|
| True and True |  True  |
| True and False |  False  |
| False and True |  False  |
| False and False |  False  |

- or 연산자: 둘 중 하나 이상이 True 라면 True

| 과정 | 결과 |
|:----:|:----:|
| True or True | True |
| True or False | True |
| False or True | True |
| False or False | False |

- not 연산자: True 는 False 로, False 는 True 로 변환
not True -> False
not False -> True

🧠 정리
비교 연산과 논리 연산의 차이를 분명하게 설명할 수 있으며,
각 연산자들의 역할과 조건문에서의 사용 목적을 이해했다.

## 9. 🐍 조건문 (if문)
- 조건문: 특정 조건의 성립여부에 따라 다른 코드를 실행하게 만드는 명령문
- 블록(Block): 들여쓰기(Indentation)으로 묶인 코드 영역

### 1. if문
- if문: 조건이 True일 경우에만 지정된 코드 블록을 실행
- 기본형: 
```python
if 조건:
    <실행할 명령 1>
    <실행할 명령 2>
    ...
```
 
설명: 
- 조건 -> False -> 종료
- 조건 -> True -> 실행할 명령 1 -> 실행할 명령 2

주의사항:
(1) 조건 뒤에 콜롱(:)을 꼭 붙임
(2) 명령을 쓸 때 Spacebar를 네번 누르거나 Tab을 한번 눌러 들여쓰기 필요
그렇지 않을 시, 파이썬이 if문의 명령이라고 인식 못함
(3) if문을 모두 입력한 후 다른 코드를 입력할 때는 들여쓰기 필요 없음

### 2. if-else문
- if-else문: 특정 조건식이 True 인지 False 인지에 따라 다른 코드 블록을 실행하는 조건문
- if 조건이 True 이면 해당 블록을 실행
- False 이면 else 블록을 실행
- 두가지 경우의 수 중 하나를 반드시 처리

- 기본형: 
```python
if 조건:
    <실행할 명령 1>
else:
    <실행할 명령 2>
```

설명:
조건 -> True -> 실행할 명령 1 
조건 -> False -> 실행할 명령 2

### 3. if-elif문
- if-elif문: 여러 조건식을 순차적으로 검사하여, 처음으로 True 가 되는 조건의 코드 블록만 실행하는 다중 조건문
- elif 는 'else if'의 약자
- 앞선 조건이 False일 때만 검사됨
-여러번 사용할 수 있어 복잡한 분기 처리에 효율적

- 기본형: 
```python
if 조건 1:
    <실행할 명령 1>
elif 조건 2:
    <실행할 명령 2>
```

설명:
조건 1 -> True ->실행할 명령 1
조건 1 -> False -> 조건 2 -> True -> 실행할 명령 2

### 4. if-elif-else문
- if-elif-else문: 여러 조건 중 처음으로 True 가 되는 조건의 코드 블록만 실행하는 조건문
- if 로 시작해 elif 로 다중조건을 추가
- else 로 모든 조건이 False 일 때 기본 실행을 처리
- 3개 이상의 경우의 수를 나눌때 사용

- 기본형:
```python
 if 조건 1:
   <명령 1>
elif 조건 2:
   <명령 2>
elif 조건 3:
    <명령 3>
...
 else:
    <명령 N>
```

설명:    
조건 1 -> True -> 명령 1
조건 1 -> False -> 조건 2 -> True -> 명령 2
조건 1 -> False -> 조건 2 -> False -> 조건 3 -> True -> 명령 3
조건 1 -> False -> 조건 2 -> False -> 조건 3 -> False -> ... -> False -> 명령 N

🧠 정리
조건문을 통해 프로그램이 상황에 따라 다른 결과를 출력하도록 제어할 수 있음을 이해했다.

## 10. 🐍 리스트 요소 조작 매서드
- 리스트 자료형의 특징
 - 대괄호 [] 안에 문자열, 숫자형, 리스트를 원소로 넣을 수 있음
 - 원소의 위치를 인덱스라 하고, 0부터 시작
 - 원소에 접근하는 방법으로: 인덱싱과 슬라이싱

### 1. append()
- append(): 리스트 맨 마지막 위치에 새로운 요소(데이터) 하나를 추가하여 리스트의 길이를 1만큼 확장하는 내장함수
- append는 '덧붙이다' 라는 의미
- 기본형: 리스트.append(d)

설명
- 리스트.append(d)에서 d는 추가할 원소를 의미 

- 점 표기법: 점(.)을 찍고 특정 함수를 사용하는 방법

🧠 정리
append()는 리스트의 끝에만 값을 추가하기 때문에,
기존 데이터의 순서를 유지하면서 값을 누적할 때 적합하다.

### 2. insert()
- insert(): 리스트의 특정 인덱스(위치)에 원하는 요소를 삽입하는 내장함수
- insert는 '삽입하다' 라는 의미
- 기본형: 리스트.insert(i,d)

설명:
- 리스트.insert(i,d) 에서 i는 추가할 원소의 위치, d는 추가할 원소를 의미

🧠 정리
insert()는 원하는 위치에 값을 추가할 수 있지만,
그 이후 요소들의 인덱스가 모두 변경된다는 점을 고려해야 한다.

### 3. remove()
- remove(): 리스트에서 특정 값을 찾아 첫번째로 일치하는 항목을 삭제하는 내장함수
- 기본형: 리스트.remove(d)

설명
- 리스트.remove(d) 에서 d는 삭제할 자료를 의미

🧠 정리
remove()는 인덱스가 아니라 값을 기준으로 삭제하므로,
같은 값이 여러 개 있을 경우 하나만 삭제된다는 점을 주의해야한다.

### 4. sort() / sorted()
#### 1. sort()
- sort(): 리스트(list)의 요소들을 일정한 기준에 따라 정렬하는 메서드
- 리스트(list)에만 사용 가능
- 리스트 자체를 직접 정렬(원본 변경)
- 변환값이 없음(None)
- 메서듸기 때문에 객체 뒤에 .sort() 형태
- 기본형: 리스트.sort()

설명:
- 소괄호 안에는 아무것도 적지 않음

🧠 정리
sort()는 리스트 자체를 정렬하므오 원보닝 변경된다.
따라서 기존 순서를 유지해야 하는 경우에는 사용에 주의가 필요하다.

#### 2. sorted()
- sorted(): 이터러블(iterable)을 입력으로 받아, 정렬된 새로운 리스트를 반환하는 파이썬 내장함수
- 내장 함수이므로 객체 없이 바로 사용
- 원본 데티어는 변경하지 않음
- 정렬 결과를 리스트 형태로 변환
- 모든 이터러블에서 사용 가능 (리스트, 튜플, 문자열, 딕셔너리 등)
- 기본형: sorted(이터러블)

##### 1. iterable
- 이터러블(iterable): 반복(iteration)이 가능한 객체
- 하나씩 순서대로 꺼내서 처리하는 객체
- for문에서 사용 가능
- iter() 함수로 이터레이터를 생상할 수 있음
- 여러 번 반복 가능

🧠 정리
iterable은 for문을 통해 순회할 수 있는 객체를 의미한다.

##### 2. iterator
- 이터레이터(iterator): 이터러블에서 생성되며, 실제로 값을 하나씩 꺼내는 객체
- next()를 통해 다음 값을 하나씩 변환
- 모든 값을 소모하면 더이상 꺼낼 수 없음
- 한 번만 순회 가능

🧠 정리
iterator는 iterable 객체를 실제로 순회하며 값을 하나씩 반환한다.

🧠 정리
sorted()는 리스트 뿐 아니라 모든 iterable 객체에 사용할 수 있으며,
정렬 과정에서 iterator를 통해 요소를 하나씩 읽어들인다.
따라서 원본 데이터를 유지하면서 정렬 결과만 필요할 때 유용하다.

#### 3. sort() 와 sorted() 의 정렬 규칙
##### 1. 기본정렬은 오름차순
- 숫자: 작음 값 -> 큰 값
- 문자열: 사전 순(유니코드 순)
- 기본형: 
리스트.sort()
sorted(이터러블)

##### 2. 내림차순 정렬 (reverse=True)
- reverse=True 를 주면 정렬 결과를 반대로 뒤집음
- 오름차순 -> 내림차순
- 기본형:
리스트.sort(reverse=True)
sorted(이터러블, reverse=True)

##### 3. 기준을 정해 정렬 (key)
- key: 각 요소에서 "정렬 기준이 될 값"을 추출하는 함수
-  실제 요소가 아니라 key함수의 변환값을 기준으로 정렬
- 기본형:
리스트.sort(key=함수)
sorted(이터러블, key=함수)

##### 4. 기준값 + 내림차순 정렬
- key로 정렬 기준을 정함
- 그 기분을 내림차순(reverse=True)로 정렬
- 기본형:
리스트.sort(key=함수, reverse=True)
sorted(이터러블, key=함수, reverse=True)

🧠 정리
리스트 메서드는 리스트에 값을 추가, 삽입, 삭제, 정렬하는 기능을 제공한다.
각 메서드는 동작 방식과 리스트에 미치는 영향이 다르므로,
데이터의 순서와 원본 유지 여부를 고려해 적절히 선택해야 한다.

## 11. 🐍 시퀀스
- 시퀀스(Sequence): 순서가 있는 데이터의 집합으로, 각 요소가 인덱스를 통해 접근 가능한 자료형
- 파이썬의 시퀀스 자료형은 인덱싱, 슬라이싱, 반복, 연결 연산과 같은 공통된 연산을 지원
- 시퀀스 자료형: 시퀀스 형태의 자료형
- 시퀀스 객체: 시퀀스 자료형으로 만든 객체
- 요소(element): 시퀀스 객체에 들어있는 각 값
- 순서(order)가 존재
- 활용 목적:
 - 문자열 처리
 - 데이터 순차 저장 및 접근
 - 반복 처리 및 데이터 분할
 - 알고리즘 문제 해결의 기본 구조
- 시퀀스 자료형에는 다섯 가지의 특징이 있음

### 1. 특징(1) 원소에는 순서가 있다
#### 1. 음수 인덱싱
- 음수 인덱싱: 시퀀스 자료형의 뒤쪽 요소부터 접근하기 위해 음수 인덱스를 사용하는 방법
- 음수 인덱스는 시퀀스의 마지막 요소를 기준으로 역순으로 계산
 - 리스트, 문자열, 튜플 등 모든 시퀀스 자료형에서 사용 가능
 - 시퀀스의 길이를 기준으로 자동 계산
 - [-1]: 항상 마지막 요소
 - [-2]: 뒤에서 두번째 요소
 - [-n]: 뒤에서 n번째 요소
 - 시퀀스의 길이를 몰라도 끝 요소에 바로 접근 가능
 - 마지막 값, 최근 값 등을 가져올 때 유용함
 - 코드 가독성이 높아짐
 - 활용 목적:
  - 마지막 요소 접근
  - 최근 데이터 참조
  - 슬라이싱과 함께 사용하여 뒤쪽 데이터 추출

  🧠 정리
  앞이 아닌 뒤에서부터 접근할 수 있다는 개념이 생기면서, 데이터 탐색이 훨씬 직관적으로 느껴졌다.

#### 2. 시작 인덱스 생략([start:])
- 시작 인덱스 생략([start:]): 슬시퀀스 자료형에서 특정 인덱스부터 마지막 요소까지를 추출하는 방식
- 부분 추출에 자주 사용
- 기본형: sequence[start:]
 - 시작 인덱스 start: 포함
 - 끝 인덱스: 생략 -> 마지막 요소까지 포함
 - 연속된 요소를 잘라내어 새로운 시퀀스로 변환
- 원본 시퀀스는 변경되지 않음
- 문자열, 리스트, 튜플 등 모든 시퀀스 자료형에서 동일하게 동작
- 끝 인덱스를 생략해도 IndexError가 발생하지 않음
- 활용 목적:
 - 특정 위치 이후의 데이터 추출
 - 헤더/앞부분 제거 후 데이터 처리
 - 문자열 접두사 제거

 🧠 정리
 처음부터 특정 위치까지를 자연스럽게 다룰 수 있어 불필요한 계산이 줄어든다는 점을 이해했다.

#### 3. 끝 인덱스만 지정([:end])
- 끝 인덱스만 지정([:end]): 시작 인덱스를 생략하고, 처음부터 특정 인덱스 직전까지의 요소를 추출하는 방식 
- 시퀀스의 앞부분을 잘라낼 때 사용
- 끝 인덱스는 항상 제외
- 연속된 요소를 새로운 시퀀스로 변환
- 원래 시퀀스는 변경되지 않음
- 문자열, 리스트, 튜플 등 모든 시퀀스 자료형에서 동일하게 동작
- 끝 인덱스는 항상 미포함(exclusive)
- 기본형: sequence[:end]
 - 시작 인덱스 -> 자동으로 0 지정
 - 끝 인덱스 end -> 포함되지 않음
- 활용 목적:
 - 문자열 앞부분 푸풀
 - 리스트에서 처음 n개의 데이터 확보
 - 데이터 전처러 및 미리보기

 🧠 정리
 데이터의 앞부분을 잘라낼 때 명확한 기준을 코드로 표현할 수 있다는 점이 인상적이었다.

### 2. 특징(2) 멤버를 조회할 수 있다
- in연산자(Membership Operator): 특정 값이 시퀀스 또는 컬렉션 자료형에 포함되어 있는지를 검사하는 멤버십 연산자
- 결과는 True 또는 False로 반환
- 조건문(if)에서 자주 사용
- 포함 여부만 판단하여, 위치(인덱스)는 반환하지 않음
- 대소문자를 구분함 (문자열 기준)
- 기본형: value in object
- 사용 가능한 자료형:
 - 문자열 (str)
 - 리스트 (list)
 - 튜플(tuple)
 - 집합 (set)
 - 딕셔너리 (dict)
  - 딕셔너리에서는 키(key) 존재 여부를 검사함
- 활용 목적:
 - 조건문에서 특정 값 존재 여부 확인
 - 데이터 검증 및 예외 처리
 - 필터링 로직 구현

 🧠 정리
 값의 존재 여부를 읽기 쉬운 조건문으로 표현할 수 있다는 점이 가장 큰 장점이라고 느꼈다.

### 3. 특징(3) 길이를 확인할 수 있다
- len(): 시퀀스 또는 컬렉션 자료형에 포함된 요소의 개수(길이)를 반환하는 파이썬 내장함수
- 반환값은 정수(int) 타입
- 공백도 문자열의 한 문자로 계산됨
- 시퀀스 자료형에 유효한 마지막 인덱스는 len() - 1
- 기본형: len(object)
- 사용 가능한 자료형:
 - 문자열 (str) -> 문자 개수
 - 리스트 (list) -> 요소 개수
 - 튜플(tuple) -> 요소 개수
 - 집합 (set) -> 요소 개수
 - 딕셔너리 (dict) -> 키(key)의 개수
- 활용 목적:
 - 반복문 범위 설정
 - 리스트 길리 확인
 - 인덱스 에러 방지
 - 조건문에서 개수 비교

 🧠 정리
 길이를 직접 세지 않아도 되어, 반복문과 함께 사용할 때 코드가 훨씬 안정적으로 된다고 느꼈다.

### 4. 특징(4) 연결 연산을 할 수 있다
- 연결 연산(Concatenation): 동일한 타입의 시퀀스 자료형을 이어 붙여 하나의 새로운 시퀀스를 생성하는 연산
- 원본 시퀀스는 변경되지 않음 (불변성 유지)
- 연결 결과는 새로운 객체로 생성
- 각 시퀀스의 요소 순서를 유지한 채 병합됨
- 기본형: sequence1 + sequence2
- 적용 가능한 자료형:
 - 문자열 (str)
 - 리스트 (list)
 - 튜플 (tuple)
- 활용 목적:
 - 연결 연산은 + 연산자를 사용
 - 동일한 시퀀스 타입끼리만 가능
 - 결과는 새로운 시퀀스로 반환

 🧠 정리
 여러 데이터를 하나의 흐름으로 이어서 새로운 결과를 만들 수 있다는 점을 이해했다.

### 5. 특징(5) 반복 연산을 할 수 있다
- 반복 연산(Repetition): 시퀀스 자료형을 지정한 횟수만큼 반복하여 새로운 시퀀스를 생성하는 연산
- 시퀀스의 요소 순서를 유지한 채 반복
- 원본 시퀀스는 변경되지 않음
- 결과는 새로운 시퀀스로 생성
- 기본형: sequence * n
 - sequence: 시퀀스 자료형
 - n: 반복 횟수 (정수)
- 적용 가능한 자료형:
 - 문자열 (str)
 - 리스트 (list)
 - 튜플 (tuple)
- 활용 목적:
 - 반복 연산은 * 연산자를 사용
 - 시쿼스 자료형에서만 가능
 - 결과는 새로운 시퀀스로 반환

 🧠 정리
 짧은 코드로 동일한 패턴을 만들 수 있어 데이터 테스트나 초기화에 유용하다고 느꼈다.

 🧠 정리
 시퀀스 단원을 통해 데이터를 단순한 묶음이 아니라 순서와 위치를 가진 구조로 이해하게 되었다.
 이후 반복문과 함께 사용되며 데이터를 다루는 기본 사고방식이 된다는 점을 느꼈다.

## 12. 🐍 반복문
- 반복문: 동일하거나 유사한 작업을 여러 번 자동으로 실행하기 위해 사용하는 제어문
- 반복문 사용시,
 - 코드가 간결해짐
 - 수정 및 유지보수가 쉬워짐
 - 대량의 데이터 처리에 적합
 
### 1. for문 (for loop)
- for문: 시퀀스나 반복 가능한 객체(iterable)의 요소를 순서대로 하나씩 순회하며 코드를 반복실행하는 제어문
- 기본형: for item in iterable:
            실행할 코드
- 동작 방식:
 (1) iterable에서 요소 하나를 가져와 변수에 저장
 (2) 블록 내부 코드 실행
 (3) 다음 요소로 이동
 (4) 모든 요소를 순회하면 반복 종료
- 활용 목적:
 - 데이터 집합 처리
 - 반복 출력
 - 누적 계산
 - 조건 분기와 함께 사용

- for문 작성시 주의사항
 (1) for, 변수, in, 시퀀스 사이에는 띄어쓰기 한칸씩 필요
 (2) in 키워드를 적은 뒤에 반복할 범위로 사용할 시퀀스를 작성
 (3) 시퀀스 뒤에는 잊지 말고 콜론(:) 작성 필수
 (4) 명령을 적기 전에 먼저 Enter를 눌러 줄 병경 필요
 (5) Tab이나 Spacebar로 들여쓰기를 한 다음 반복할 명령을 입력
 (6) 명령문이 여러 개일시, 이어서 Enter로 줄 바꾸고 (5)처럼 들여쓰기 한 다음 명령무 작성

 🧠 정리
 반복 구조가 명확해 코드의 흐름을 한눈에 파악할 수 있다는 점이 좋았다.

### 2. range() 함수
- range(): 연속된 정수 시퀀스를 생성하는 파이썬 내장함수
- 주로 반복문(for)에서 반복 횟수를 지정할 때 사용
- 필요할 때 값을 하나씩 만들어내는 시퀀스 객체
- 기본형: range(start, stop, step) 

- range(a): 0부터 a-1까지의 정수 시퀀스 생성
 - 시작 값: 0 (자동)
 - 종료 값: a (포함X)
 - 총 반복 횟수: a번
 - 반복 횟수가 a번인 반복문을 만들 때 가장 기본적으로 사용

- range(a,b): a부터 b-1까지의 정수 시퀀스를 생성
 - 시작 값: a (포함)
 - 종료 값: b (포함X)
 - 증가 값(step): 1 (기본값)
 - 시작값과 종료 값을 명확히 제어하고 싶을 때 사용

- for item range(a): 0부터 a-1까지의 정수 값을 하나씩 item에 대입하며 반복하는 반복문
- 반복 횟수가 a번 고정된 경우에 가장 기본적으로 사용
 - 시작 값: 0 (자동)
 - 종료 값: a (포함X)
 - 총 반복 횟수: a번
 - item은 반복 중 현재 값을 의미하는 변수

- for item in range(a, b): a부터 b-1까지의 정수 값을 순서대로 item에 대입하여 반복하는 반복문
- 반복의 시작 값과 종료 범위를 명확하게 지정하고 싶을 때 사용
 - 시작 값: a(포함)
 - 종료 값: b(포함X)
 - 증가 값(step): 1 (기본값)
 - 총 반복 횟수: b - a 번

 🧠 정리
 숫자의 시작과 끝을 직접 제어하면서 반복 횟수를 의도대로 설정하는 감각이 생겼다.

### 3. while문
- while문: 주어진 조건식이 True인 동안 반복해서 코드를 실행하는 문법
- 반복 횟수가 정해져 있지 않음
- 조건의 변화에 따라 반복을 종료해야 할 때 사용
- 기본형: while condition:
               실행할 코드
  - condition 이 True -> 반복 실행
  - condition 이 False -> 반복 종료
- while문 사용시 주의사항
 (1) while 다음에 한 칸을 띄고 조건 작성
 (2) 조건 뒤에 콜론(:) 작성
 (3) 명령을 적기 전에 Enter 를 눌러 줄 바꿈
 (4) Tab 이나 Spacebar 로 들여쓰기를 한 다음 반복할 명령을 입력
 (5) 명령이 여러 개일시, Enter 로 줄 바꾼 후 (4) 처럼 들여쓰기를 한 다음 명령 입력 

🧠 정리
조건이 중심이 되는 반복이라, 논리적으로 흐름을 생각하는 연습이 된다고 느꼈다.

### 4. break문
- break문: 반복문(for, while)을 즉시 종료하기 위해 사용하는 제어문
- 조건이 만족되는 순간 남은 반복을 모두 건너뛰고 반복문을 종료
- 사용 위치:
 - for 반복문 내부
 - while 반복문 내부
 - 주로 특정 조건을 만족했을 때 반복을 중단하기 위해 사용
- 기본형: 
 while condition:
  if exit_condition:
     break

 for item in iterable:
  if exit_cindition:
     break

- break문은 반드시 반복문 내부에 위치해야 함
- 들여쓰기 위치에 따라 반복 종료 시점과 동작 결과가 달라짐

🧠 정리
원하는 시점에 반복을 멈출 수 있어 프로그램 흐름을 스스로 통제하고 있다는 느낌을 받았다.

🧠 정리
반복문을 통해 같은 작업을 효율적으로 처리하는 사고방식을 익히게 되었다.
코드의 양보다 흐름과 조건을 설계하는 것이 중요하다는 점을 느낀 단원이었다.

## 13. 🐍 자료형 매서드 심화 (List & String Methods)
🎯 Why This Matters
 실무에서 다루는 대부분의 데이터는 문자열(String) 또는 리스트(List) 형태로 들어온다.

 특히 다음과 같은 상황에서 필수적으로 사용된다.
 - Game log parsing
 - CVS 데이터 처리
 - Match result analysis
 - Runtime data structure control

### 1. .pop()
- pop(): 리스트(List)에서 특정 위치의 요소를 제거하고 그 값을 반환하는 매서드 (Controlled Data Removal)
- 반환: 함수를 사용하려고 불러낸 위치에 결괏값을 알려주는 것
- 기본형: list.pop(index)
- index를 생략하면 마지막 요소를 제거
- 제거된 값을 리턴(return)이라고 함
- 원본 리스트 변경 (mutable)
- 잘못된 인덱스 -> IndexError
- 빈 리스트에서 호출 -> IndexError
- pop(0) 은 O(n)
- pop()(last element)는 O(1)
- 대규모 데이터에서 pop(0)은 비효율적
- collections.deque 사용을 고려


### 2. count()
- count(): 시퀀스 내 특정 값의 정확한 등장 횟수를 반환 (Frequency Analysis)
- 기본형: sequence.count(value)
- list/tuple/string에서 사용 가능
- 문자열은 대소문자 구분
- 겹치는 부분 문자열은 세지 않음
- 시간복잡도 O(n)
- 대규모 데이터에서는 dict 또는 collections.Counter 기반 분석이 효율적

### 3. split()
- split(): 문자열을 특정 구분자를 기분으로 분리하여 리스트로 반환 (Parsing Raw Text)
- 기본형: string.split(separator)
- 기본 구분자: 공백
- 반환값: list[str]
- 결과는 항상 문자열 리스트
- 숫자 사용 시 int() 변환 필요
- 구분자 지정 여부에 따라 결과 구조 달라짐
- Raw Text -> split() -> Structured List
  
### 4. .join()
- join(): 문자열 iterable을 하나의 문자열로 결합 (Structured Output Formatting)
- 기본형: separator.join(iterable)
- 모든 요소는 반드시 문자열
- Processed List -> join() -> Structured Output
